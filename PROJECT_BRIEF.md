# ESP32-C3 Mesh Chat — краткий бриф проекта

> Одностраничное описание для быстрой передачи проекта новому
> исполнителю (человеку или ИИ). Намеренно **без нюансов**: точные
> форматы и числа — только в `protocol/` и `docs/`, для работы их
> нужно смотреть там.

## Суть (для предзащиты)

Чат без интернета. Несколько плат ESP32-C3 обмениваются сообщениями
напрямую по радио (ESP-NOW, без Wi-Fi-роутера и без сервера) и
образуют mesh-сеть с ретрансляцией через промежуточные узлы. К любой
плате с телефона или ноутбука можно подключиться по Bluetooth
(Web Bluetooth в Chrome) — она становится BLE-шлюзом, и браузер
работает как полноценный клиент чата: отправка сообщений, приём
чужих, статусы доставки, карта узлов и маршрутов. Всё работает
офлайн.

## Как устроено

- **Три компонента:**
  1. **Прошивка** — PlatformIO + Arduino (C++), ESP32-C3;
     BLE — NimBLE, радио — ESP-NOW.
  2. **Mesh-ядро** — отдельная библиотека без зависимости от Arduino
     (пакеты, маршрутизация с TTL, дедупликация, таблица узлов);
     покрыта нативными юнит-тестами + симулятором сценария.
  3. **Веб-клиент** — ванильный JS без фреймворков и без сборки;
     Web Bluetooth-транспорт + заглушка-транспорт для разработки
     без железа.
- **Одна прошивка на все платы.** Роль шлюза — не назначение, а
  поведение: плата становится шлюзом, когда к ней подключается
  BLE-клиент.
- **Радио-транспорт:** ESP-NOW broadcast + ретрансляция с ограничением
  числа прыжков (TTL); повтор пакетов отсекается кэшем дедупликации.
- **Транспорт клиент–плата:** BLE GATT по модели Nordic UART
  (запись + уведомления), поверх MTU — собственное кадрирование
  (длина + CRC), MTU до 256 байт. Обмен — компактные JSON-команды и
  события.
- **Статусы сообщений сквозные:** принят → отправлен →
  доставлено/не доставлено; доставку подтверждает ACK от узла
  получателя, маршрут и число прыжков видны клиенту.
- **Имя узла привязано к плате** и задаётся при первом подключении
  из приложения.

## Состояние

- Веб-клиент — готов и проверен вживую в Chrome (включая реальный
  Web Bluetooth).
- Прошивка — mesh-логика готова, юнит-тесты проходят; BLE-шлюз
  работает на живой плате (первое подключение и BLE-проверка
  пройдены).
- **Дальше:** вторая плата — ESP-NOW вживую; затем BLE + ESP-NOW
  одновременно; затем три платы и демонстрация маршрута
  через ретранслятор.

## Правила работы (критично)

- **Прошивка платы — каждый раз с отдельного разрешения
  пользователя.**
- Коммит и пуш после каждого логического блока; **сообщения коммитов
  на русском**.
- Числовые параметры протокола в коде помечены `[ПРОВЕРИТЬ]` —
  согласованы, но не все проверены на железе; не считать окончательными.
- Тесты mesh-ядра запускаются нативно (без железа) — гонять перед
  коммитом кода прошивки.

## Как подключиться к работе (чек-лист нового исполнителя)

1. Прочитать `docs/WORKFLOW.md` и `docs/INSTRUCTIONS.md`.
2. Сверить состояние: `git log --oneline -5`, `git status`.
3. Открыть нужный этап в `docs/stages/README.md` — файл этапа
   самодостаточен.
4. Точный формат кадра/JSON при необходимости — в `protocol/`:
   бриф сознательно не дублирует эти детали.
