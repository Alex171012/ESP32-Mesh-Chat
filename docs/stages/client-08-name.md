# Этап 8 клиента — имя узла и первый запуск

> **Требуется:** браузер Chromium. Железо не нужно.
> **Предыдущий этап:** `client-03-mock.md`.

## Цель

Реализовать привязку имени к плате: диалог при первом подключении,
смена и сброс имени из приложения.

## Контекст

Продуктовое решение (подтверждено пользователем): **имя привязано к
плате**, хранится в NVS, задаётся при первом подключении. Системы
пользователей нет (`BLE_API.md` §7.2–7.4).

Протокол (`BLE_API.md` §4.1):

| Команда | Ответ |
|---|---|
| `get_name` | `{"t":"name","name":null\|string,"assigned":bool}` |
| `set_name` | ответ `name` |
| `clear_name` | `assigned: false` |

Правила имени:

- UTF-8, **не более 24 байт**;
- без управляющих символов;
- при превышении — `{"t":"err","code":"name_too_long"}`;
- узел без имени показывается как `Узел <node_id>`.

## Что сделать

1. При подключении сразу `get_name()`.
2. Если `assigned: false` — показать диалог ввода имени. Это первый
   запуск, момент знакомства с платой.
3. Валидация на клиенте **до отправки**: длина в байтах (русская буква —
   2 байта), запрет управляющих символов. Не полагаться только на ответ
   прошивки.
4. Смена имени — из панели узлов (этап 5).
5. Кнопка сброса имени. Подтверждение обязательно: сброс затрагивает
   плату, а не приложение.
6. Показывать имя шлюза в области состояния связи.
7. Учесть `name_too_long` понятным текстом, если прошивка всё же
   отказала.

## Про сброс

**Сброс имени делается из приложения**, а не кнопкой на плате. Кнопки
`RST` и `BOOT` для этого не используются (`BLE_API.md` §7.4):

- `RST` — аппаратный сброс, прошивка его не видит;
- `BOOT` (GPIO9) — strapping-пин, его нельзя удерживать при включении.

Долгое удержание `BOOT` как аварийный способ — **после v1**.

## Ловушки

- **24 байта, а не 24 символа.** Русское имя из 12 букв уже предел.
- **Не отправлять пустое имя** — для этого есть `clear_name`.
- Диалог показывать один раз при `assigned: false`, а не при каждом
  подключении.

## Проверка

На заглушке, `index.html?mock=1`:

- Первое подключение → диалог имени, `assigned: false`.
- Ввод 30 русских букв → отказ на клиенте, команда не уходит.
- Ввод 12 русских букв → имя сохраняется, показывается в ленте и в
  области связи.
- Сброс → `assigned: false`, узел снова показан как `Узел <node_id>`.
- Переподключение → диалог больше не появляется.

## Критерий готовности

Имя задаётся при первом подключении, меняется и сбрасывается из
приложения, валидация не пропускает длинное имя до отправки.

## Коммит

```
Имя узла: диалог первого подключения, смена и сброс

Реализованы команды get_name, set_name, clear_name, проверка
длины имени в байтах до отправки и сброс имени из приложения
без использования кнопок платы.
```
